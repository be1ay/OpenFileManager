# Belkin Commander
[![C++ CI](https://github.com/be1ay/OpenFileManager/actions/workflows/release.yml/badge.svg?branch=main)](https://github.com/be1ay/OpenFileManager/actions/workflows/release.yml)

Кроссплатформенный файловый менеджер, вдохновлённый классическими инструментами вроде Total Commander.
Проект построен на чистой архитектуре, разделяющей ядро, плагины и UI, и использует Qt для реализации интерфейса и работы с файловой системой.

## 🚀 Основные возможности
- Две независимые файловые панели (активная/пассивная)
- Копирование файлов и директорий в отдельном потоке
- Удаление файлов
- Создание новых папок
- Переименование файлов и папок
- Прогрессбар копирования (через плагин CopyPlugin)
- Система сигналов CopySignals для UI‑интеграции
- Поддержка больших файлов (поблочное копирование)
- Кроссплатформенная работа (Windows / Linux)
- Плагинная архитектура (расширяемость без изменения ядра)

## 🧩 Архитектура проекта
### 1. Core (ядро)
Содержит всю бизнес‑логику и не зависит от UI.
| Компонент | Назначение  | 
| :-------- | :------- |
| `FileOperations` | `Высокоуровневые операции над файлами (копирование, проверка путей, подготовка задач).` |
| `CopyWorkerCore` | `Низкоуровневый поток копирования, работающий поблочно.` |
| `CopySignals` | `Сигналы для передачи прогресса и статуса в UI.` |
| `ApplicationAPI` | `Интерфейс для плагинов, позволяющий расширять функциональность.` |

### 2. UI (приложение)
Отвечает за визуальное представление и взаимодействие с пользователем.
#### Основные элементы:
- MainWindow — главное окно, управляющее панелями.

- FilePanel — одна файловая панель.

- FileView — кастомный QTreeView с drag&drop.

- CopyProgressDialog — окно прогресса копирования. (реализовано как плагин)

- Integration с CopySignals — отображение статуса копирования.

#### Особенности:
- UI не содержит бизнес‑логики.

- Все операции делегируются в Core.

- Панели полностью независимы.

### 3. Plugins (плагины)
Расширяют функциональность без изменения ядра.

#### Возможности:
- Подключение внешних модулей.

- Доступ к ApplicationAPI.

- Реализация собственных команд, обработчиков, UI‑элементов.

#### Примеры:
- CopyPlugin - плагин отображающий прогресс бар при копировании.

- FileOperationsBtn - плагин добавляющий кнопки операций.

- DuplicateFinder - плагин для поиска дубликатов файлов

- ExamplePlugin — демонстрация API.
